### 🤖 IntelliGent AI Tutor System

IntelliGent AI Tutor System is an AI-powered learning assistant built using Streamlit, LangChain, and Groq LLMs.

## Features
- Topic Classification
- AI Generated Explanations
- Python Code Generation
- Technical Keywords Extraction
- Learning Resources

## Tech Stack
- Python
- Streamlit
- LangChain
- Groq API

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
